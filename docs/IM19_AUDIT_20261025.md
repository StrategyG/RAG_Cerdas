## Impact analysis and repair

1. New private `im19` schema and package isolate knowledge publication from the legacy `rag` index. No legacy rows, Dropbox originals, existing migrations or source documents are deleted or overwritten.
2. Legacy `PDFSource` now delegates remote reads to the OAuth-capable read-only client. Its environment token adapter is compatibility support, not the recommended secret-manager path. Local reads remain independent.
3. Preflight checks Dropbox metadata instead of downloading a PDF; local PDFs remain eligible when Dropbox is blocked. Supabase is still required by that legacy pilot gate.
4. New `im19` ingestion stages records without publication, runs role-specific model reviews, and requires a separate human approver while rubric/benchmarks remain uncalibrated. Source attribution is not factual verification.
5. The new migration is additive and never auto-applied. Existing `rag` migrations still require their historical base schema; the new schema is independently testable after pgvector installation.
